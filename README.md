# School Tools

Small web tools for St. Joseph's Primary School.

- [Book Check](book-check/) — scan class books with a phone and see whether a class is complete.
- [Book Labels](book-check/labels.html) — print thin Code 128 spine labels for BookIDs.
- [Search Practice](search-practice/) — P2 practice search engine with fake results and scam pop-ups; [teacher dashboard](search-practice/teacher.html).
